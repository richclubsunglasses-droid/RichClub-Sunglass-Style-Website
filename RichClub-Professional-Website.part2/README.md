# RICHCLUB Professional Storefront

A responsive Next.js storefront for RichClub premium eyewear.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Main redesigned product route:

`/product/rich-club-polarised-sunglasses-with-uv-protection-unisex-wayfarer`

## Included

- Responsive premium homepage and navigation
- Search and collection filtering
- Redesigned product gallery and product information hierarchy
- Quantity, Add to Bag and Buy Now interactions
- Local-storage cart
- Shop, search, cart, account, about, contact and policy routes
- SEO metadata and accessible interaction states
