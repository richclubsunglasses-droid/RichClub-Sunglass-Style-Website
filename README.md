# RICHCLUB — Sunglassic-style storefront

This project is a fresh RichClub storefront inspired by the information architecture and shopping flow of modern eyewear stores such as Sunglassic. It does not copy their source code, branding, text, or proprietary assets.

## Run
1. Open this folder in VS Code.
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:3000`

## Included routes
- `/` Home
- `/shop` collection + filters
- `/product/[slug]` product detail
- `/search` search
- `/cart` cart with localStorage
- `/about`
- `/contact`
- `/account`
- `/policies/shipping`
- `/policies/returns`
- `/policies/privacy`
- `/policies/terms`

## Important
The included product images are the image assets already present in the uploaded RichClub project. Replace/add your real catalogue images and final business policies before going live. Payment, authentication, order database, shipping API and WhatsApp integration are intentionally left as connection points.
